ControlPhone remote

Live picture, blackout, scenes, layers and the show from the phone.

Control VJ-Link from a phone in the same Wi-Fi: start clips (with preview pictures), change colours and the colour slots, tap the tempo, set strobe speed and intensity, and hold strobe, strobe white and blinder. Nothing to install: the phone opens a page that VJ-Link serves itself, only in the local network.

  1. Phone remote in the list of connections.
  2. Switch: on starts the remote. After every start of VJ-Link it is off.
  3. Network address: the Wi-Fi or LAN of this computer that the phone is in (127.0.0.1 = this computer only).
  4. QR code: scan it with the phone camera; it opens the page and pairs at once.
  5. Or type the address into the phone browser …
  6. … and enter the 8-digit pairing code.

New in 0.1.16: four tabs at the top sort everything you need live. At the bottom, tempo, TAP and the hold buttons for strobe, strobe white and blinder are always there.

  1. The tabs Start, Scenes, Layers and Show.
  2. Live: a small picture of what the outputs show (about three frames per second, only while this tab is open).
  3. BLACKOUT: tap on, tap off; red while it is on.
  4. Master and Effects as sliders.
  5. Scene: back, Auto, next, with the current scene.
  6. Show: GO with what it starts (only when there are cues).
  7. Tempo: type the BPM or move it by ±0.1.
  8. Light: strobe speed and intensity, strobe, strobe white and blinder latched.
  9. Setup: test pattern on and off and step through, to line up projectors right at the screen.
  10. Keep screen awake: the phone does not lock during the show.
  11. Always at the bottom: tempo, TAP and the hold buttons.
  1. All scenes; the active one is highlighted.
  2. Back, Auto and Next.
  3. Fade: duration of the transition (beats or seconds as in the program).
  4. Transition type with ◀ ▶ (fade, black, wipe …).
  1. Mixer: every layer with its opacity; tap the name to select the layer.
  2. The layer whose clips are shown.
  3. Clips with preview pictures; tap to start, Stop layer to stop.
  4. Blend mode of the layer.
  5. Text: change the text of a text clip, e.g. “Next: DJ Max”; the screen shows it at once.
  6. Colours: slot A–E, colour, Apply to layer.

A layer with a clock or countdown clip also shows its settings here: target time, minutes, the line above, the text at 0 and Restart. With several pictures (projection mapping, each output its own picture) a row at the top chooses the picture you edit.

  1. Playing with the time left, and next.
  2. GO with what it does.
  3. Back and Stop all (tap twice, so a slip does not black out the show).
  4. The running order: tap a cue to make it the next one.
  5. Timecode: start, stop and back to the start of VJ-Link's own timecode clock.

On the home screen

The remote can sit on the home screen like an app: iPhone Share → Add to Home Screen, Android browser menu Add to Home screen. It uses the fixed port 48731, so the icon still fits after VJ-Link restarts; then pair once again (the code is new after every start). If the port is taken, VJ-Link uses a free one and the QR code shows it.

✎Note

Keep screen awake uses the browser's wake lock where it is allowed; over plain http in the local Wi-Fi many phones only allow a small invisible video instead. Not yet tested on every phone: check it before the show.

Security

  • Off by default and after every start; on only while the switch is on.
  • Reachable only at the chosen local address, on port 48731 (or a free one); no internet, no cloud.
  • The phone may only set the controls listed above (master, blackout, effects, scenes, transition, test pattern, opacity and blend mode of the layers, text and clock clips, cues); settings, mapping and projects stay on the computer.
  • Pairing with an 8-digit code, a few attempts per half minute; a new pairing ends the old one.
  • The connection is not encrypted (http). Use it only in your own, trusted network, not in an open guest Wi-Fi.

Troubleshooting

ProblemSolution
The phone does not open the pagephone and computer must be in the same network; choose the matching network address; some guest Wi-Fis block devices from each other
macOS: the page loads on the computer, but not on the phoneallow incoming connections for VJ-Link in the macOS firewall
“Session ended. Please pair again.”the remote was switched off or another phone paired; scan the QR code again
The live picture stays emptyit only runs on the tab Start and while the page is visible; with a weak Wi-Fi it takes a moment
No QR codewith 127.0.0.1 there is none (the phone cannot reach it); choose the Wi-Fi or LAN address
