HelpTroubleshooting

What to check first, and how to tell us.

The output stays black

  • Is BLACKOUT on, or the master at 0? Is a clip running on a layer with opacity above 0?
  • A desk on Art-Net: master channel 1 at 0 makes everything black, channel 8 above 250 is blackout.
  • A camera mask (Mask positive) on the top layer without a person in the picture shows nothing; that is right.

The desk does not arrive

  • CONNECT shows the packets: does the counter rise? If not, check network, IP range and (Windows) the firewall for private networks.
  • Art-Net universes count from 0, sACN from 1. Check the start address.
  • Only changing channels take effect: move the fader once.

No camera

  • macOS: System Settings → Privacy & Security → Camera → switch on VJ-Link, then restart VJ-Link.
  • OBS Virtual Camera only appears while OBS runs and the virtual camera is started.
  • The person detection needs a second or two to start the first time.

LJ-Link is not found

  • Both computers in the same network, Wi-Fi and cable count as the same network if the IP range matches.
  • Enter the address under CONNECT → LJ-Link (for example 192.168.1.20 or 192.168.1.20:8080).

A video does not play

MP4 with H.264 and WebM always work. Convert other files, for example with HandBrake.

Report a problem

In VJ-Link: Help → Report a problem (also under Settings and on the start screen). Describe what happened and what you did before, leave Include diagnostic data ticked, and send it by email to fehlermelden@nextphilm.de or as a GitHub issue.

The diagnostic data holds the version, system, graphics card, connected devices, the state of the connections and the last error messages. No file names, no texts, no titles, no passwords. Too long for a mail link? It is saved as a file and copied to the clipboard.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
