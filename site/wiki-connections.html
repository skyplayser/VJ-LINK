ControlConnections

Everything that talks to VJ-Link, in one place.

The CONNECT tab collects everything that talks to VJ-Link from outside. On the left the list of all connections, each with a switch and a status; on the right the settings of the one you click.

  1. List of all connections: Art-Net, sACN, DMX channels, OSC, LJ-Link, Ableton Link, MIDI, audio input, timecode. Arrow keys ↑↓ move through it.
  2. Switch: turns the connection on or off. Off frees the network port.
  3. Status: ready, receiving, connected, off or error.
  4. Settings of the selected connection with name and status.
  5. Fields such as universe, port or address; changes apply at once.
  6. Live lines: port, packets, sender, warnings (e.g. wrong universe).
  7. Help text for this connection.
StatusMeaning
● receiving / connected (green, glowing)data arrived in the last two seconds
● ready (dark green)listening, but nothing has arrived yet
● off (grey)switched off, the port is free
● error (red)the port is taken by another program, or the network is missing; the reason is in the live lines

Art-Net

The standard way from a light desk over the network. VJ-Link listens on UDP port 6454 on all network ports. Set the universe the desk sends VJ-Link on (counted from 0, as most desks do). If the desk sends on another universe, a yellow line says which one.

✓Tip

Lighting software on the same computer (e.g. Daslight) also wants port 6454. If you only use sACN or MIDI from it, switch Art-Net off in VJ-Link.

sACN (E1.31)

sACN comes as multicast on UDP port 5568. Set the universe (counted from 1). VJ-Link joins the multicast group on every network port, also on a cable plugged in later.

DMX channels

The start address decides where the 91 channels of VJ-Link begin in the universe (1–422). Save channel list (CSV) writes the list for your desk's patch. The live values show all 91 channels as bars as they arrive; the color slot channels are pink. Art-Net and sACN share these settings.

What every channel does: desk basics and channel list.

OSC

OSC comes in on a UDP port (8000 unless you change it; 1024–65535). The live lines show packets and the last sender. Addresses: /vjlink/scene/go 3, /vjlink/scene/next, /vjlink/ctl/master 0.8 and every control as /vjlink/ctl/<id>; full list in the reference.

LJ-Link

VJ-Link finds LJ-Link by itself, on the same computer and in the network (Bonjour), and shows where it is connected. Only if it is not found (e.g. in another network) type its address or address:port. Open LJ-Link opens its web interface. Below: the now-playing lower third and the decks with BPM, key, title, ON AIR and phrase. More in VJ-Link and LJ-Link.

Ableton Link

Tempo and beat with Ableton Live, Traktor, Rekordbox and every Link app. VJ-Link talks Link through the free helper program Carabiner (TCP port 17000): start Carabiner on the same computer and VJ-Link connects by itself and shows the peers and the BPM. Off: VJ-Link stops trying.

MIDI

Shows the MIDI inputs and outputs. Off: VJ-Link ignores all MIDI input (controllers, clock, timecode), e.g. when another program should get the controller. Assign controls starts the MIDI mapping mode.

Audio input

Shows the chosen input with a level meter. Choose input opens Settings → Audio. Details: audio input.

Timecode

Shows incoming (▼) and outgoing (▲) timecode. A yellow line warns when the source of the reception (Art-Net or MIDI) is switched off. Settings and details: timecode.
