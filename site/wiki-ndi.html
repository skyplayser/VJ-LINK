OutputsNDI® output

Send the picture into the network.

VJ-Link sends its picture as an NDI® source into the network, for example to VD-Link (video walls), OBS, Resolume or an NDI monitor. It renders the picture invisibly in exactly the chosen size, without a window or a screen, so it also works on Windows without a virtual monitor. VJ-Link only sends; it does not receive NDI.

Setting up

  1. Install the NDI runtime once. VJ-Link uses the free runtime from NDI and does not ship it. It is part of the NDI Tools; if it is missing, the NDI row shows Get NDI runtime.

  2. OUTPUT → NDI® output: choose name, size and frame rate, then Send.

  3. The source appears in the network as “COMPUTER (name)”. The row shows the frames per second sent and the connected receivers.

  4. Under Arrangement every NDI output is an output like a screen: on the canvas it gets its part, in mapping its own canvases and masks.

  5. Is the computer on several networks (Wi-Fi and cable)? Choose the adapter of the video network under Settings → NDI, see below.

  1. Name of the source in the network.
  2. Size: 720p to 4K, portrait, or Custom size …, e.g. 2816 × 640 for a row of LED panels.
  3. Frame rate: 25, 30, 50 or 60 per second.
  4. Status: name in the network, frames per second, receivers.
  5. Send / Close.
  6. + NDI output: up to four sources, e.g. wall and ceiling with their own LED processor. Remove last takes the last one away.
  7. Trademark notice with a link to ndi.video.

✓Tip

VJ-Link remembers name, size and frame rate. An NDI output that was sending when VJ-Link quit sends again after the next start; only Close switches it off for good.

Settings → NDI

The gear → NDI (or NDI settings in the NDI row under OUTPUT) shows which NDI runtime VJ-Link uses, over which network adapter NDI sends, and how every NDI output is doing right now. The page refreshes every second.

  1. Version and file of the installed NDI runtime, e.g. NDI 6.3.2.0. Shows not installed if it is missing.
  2. Get a newer NDI runtime opens NDI's download page. Restart VJ-Link after installing.
  3. Send NDI via: Automatic (all adapters) or one network adapter with its address.
  4. State of the adapter: NDI sends only via it, or it is not connected right now (then NDI uses all adapters until it is back).
  5. Every NDI output: name in the network (COMPUTER (name)), size, frame rate, approximate data rate, and while sending the frames per second and the connected receivers.
  6. Together: the data rate of all sending outputs, with a warning when it needs gigabit cable.
  7. Set up in OUTPUT: name, size, frame rate, more outputs and Send/Close are set there.
  8. Trademark notice with a link to ndi.video.

Which network adapter?

  • Automatic is right as long as the computer is in only one network.
  • With Wi-Fi and cable at the same time, choose the adapter the receivers are connected to. Otherwise NDI may send the picture over Wi-Fi, and the receiver shows the source late, stuttering or not at all.
  • Changing the adapter restarts running NDI outputs (about one second without picture). VJ-Link also restarts them by itself when the adapter gets a new address, e.g. after replugging the cable.
  • Technically VJ-Link gives its NDI process its own NDI configuration with only this adapter (ndi.adapters.allowed). Your own NDI settings, e.g. a discovery server from NDI Access Manager, stay in it.

Network and performance

  • NDI runs in its own process: an error there does not stop VJ-Link.
  • Before Send nothing of NDI is loaded and nothing goes into the network.
  • Rule of thumb for the data rate: 1920 × 1080 at 60 frames per second about 250 Mbit/s, at 30 about 125 Mbit/s; it grows with size and frame rate. Settings → NDI shows it per output and in total.
  • Two or more NDI outputs need gigabit cable all the way to the receiver. On Wi-Fi or with a 100 Mbit adapter rather one output at 30 frames per second or 1280 × 720.

Troubleshooting

ProblemSolution
The row shows Get NDI runtimeinstall the NDI runtime or the NDI Tools, then restart VJ-Link
“Sends” with frames, but no receiver finds the source (macOS)System Settings → Privacy & Security → Local Network: allow VJ-Link (and the VJ-Link helper, if listed)
No receiver finds the source (Windows)allow VJ-Link in the Windows firewall for private networks (Windows asks the first time); NDI needs mDNS/Bonjour to be found
Frame rate dropsuse 30 frames per second or a smaller size, prefer a network cable over Wi-Fi
With two NDI outputs one source is missing or stays black at the receiverlook at Settings → NDI: does each output show receivers: 1? If the computer is also on Wi-Fi, choose the adapter of the video network; check that the data rate in total fits the network (gigabit cable, no 100 Mbit adapter)
“NDI does not create the source”a source with this name already exists on this computer (a second VJ-Link or another program): choose another name
Two sources with the same namenot possible: every NDI output needs its own name
Windows with display scaling (e.g. 125 %): the receiver is connected, but 0 frames/s arrivefixed in 0.1.15: update VJ-Link. VJ-Link now brings every picture to the NDI size you set, whatever the scaling
