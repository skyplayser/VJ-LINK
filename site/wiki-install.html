StartInstall and update

macOS and Windows, with the warnings on the first start.

Which file

ComputerFile
Mac with Apple chip (M1 and newer)VJ-Link-macos-arm64.dmg
Mac with Intel processorVJ-Link-macos-intel.dmg
Windows 10 / 11, 64 bitVJ-Link-windows.exe

macOS

  1. Open the .dmg and drag VJ-Link into Applications.

  2. Start VJ-Link once. macOS says “VJ-Link” Not Opened: press Done.

  3. System Settings → Privacy & Security, scroll down, Open Anyway, confirm, then Open.

  4. Allow the camera, the microphone and the local network when macOS asks and you need them.

✎Note

Camera blocked? System Settings → Privacy & Security → Camera → switch VJ-Link on and restart VJ-Link. The program also offers a button for this.

For experts, this removes the warning for good. It switches off macOS's download check for this app, so only use it for a copy from the official GitHub page or website:

xattr -dr com.apple.quarantine "/Applications/VJ-Link.app"

Windows

  1. Start VJ-Link-windows.exe. In the SmartScreen window press More info, then Run anyway.

  2. Click through the installer.

  3. When the firewall asks, tick Private networks and allow access. Without it Art-Net, sACN, OSC and LJ-Link cannot reach VJ-Link.

!Warning

Windows is built but not tested yet in this beta. Please tell us how it runs: report a problem.

Updates

VJ-Link asks GitHub for a new version at start and then at most once an hour; Settings → Update does it on request and has the switch Check for updates automatically. GitHub sees the IP address of the computer and the program version, nothing else. Download and install loads the new version and compares it with the SHA-256 checksum GitHub publishes; if they differ, nothing is installed. Then on a Mac VJ-Link quits, replaces itself and starts again; on Windows the installer opens. The project is saved all the time, nothing is lost.

Live safety

Fast flashes, strobe and strong colour changes can trigger seizures in people with photosensitive epilepsy. Keep the flash rate low (at most three flashes per second), announce strobe effects where the venue requires it and follow the venue's rules. Do not aim bright projector beams through haze at the audience at eye level. Software can fail: keep a fallback ready for the show.

VJ-Link shows this notice once before the first output. Settings → Safety → Safe flashes (on by default) limits strobe, strobe white, layer strobe, colour strobe and beat invert to three flashes per second.

Network

Art-Net, sACN, OSC and the LJ-Link input have no login – that is the industry standard. Keep the show network apart from guest Wi-Fi and allow VJ-Link in the firewall only for the private show network.

✓Tip

Update at home, not at the gig. Without internet the check just says it could not reach GitHub.

💬Something missing or wrong?

Ask in our Discord or report a problem. Reports from real gear help most, also when something does not work.
