ShowProjects

Save, move and start shows.

VJ-Link saves the working state all the time; a crash or a power cut loses nothing. To keep a show or take it to another computer, save it as a project file.

  • File menu or the project button at the top: New (⌘N), Open (⌘O), Save (⌘S), Save as (⇧⌘S), recently opened.
  • A .vjlink file contains layers, scenes, cues, mappings, outputs and the graphics. Videos go into a folder name Medien next to it; move both together.
  • A dot next to the name means unsaved changes.

Start screen and demo

The start screen offers continue, a new project with six prepared layers, open a file and Open demo: a finished show with eight layers, ten scenes with their own transitions, modulations and a timeline show. Take it apart to learn how VJ-Link works.
