ShowProjects

Save, move and start shows.

VJ-Link saves the working state all the time; a crash or a power cut loses nothing. To keep a show or take it to another computer, save it as a project file.

  • File menu or the project button at the top: New (⌘N), Open (⌘O), Save (⌘S), Save as (⇧⌘S), recently opened.
  • A .vjlink file contains layers, scenes, cues, mappings, outputs and the graphics. Videos go into a folder name Medien next to it; move both together.
  • A dot next to the name means unsaved changes.

Show package for USB

For a gig on another computer: Show package for USB … in the project menu writes the project with all graphics and videos into a new folder (e.g. on a USB stick) and checks it right away. If a file is missing, VJ-Link names it and removes the incomplete folder. Check show package … checks an existing package on the stick before the show, without the media library of this computer.

  1. Show package for USB …: choose a folder; VJ-Link creates “VJ-Link-Show-…” in it with Show.vjlink and the media folder.
  2. Check show package …: choose the Show.vjlink on the stick; the message says “complete” or names what is missing.

Start screen and demo

The start screen offers continue, a new project, open a file and Open demo. New project (also ⌘N) asks how to start: With starter setup or as an Empty project. The starter setup is minimal and made for the club: six layers (space, lines, beat, laser, text, logo), black and white with a few strong accents, and eight scenes from calm to drop. The demo is a whole party night for pop house and techno, deliberately over the top: eight layers, 14 scenes from Disco House to Peak Time with their own transitions, full effect stacks, modulations and a timeline show. Take it apart to learn how VJ-Link works.

  1. With starter setup: six layers with clips and effects, eight scenes, ready to play.
  2. Empty project: four empty layers, no clips, no scenes, nothing running. Fill the rows yourself from the GALLERY.

Start animation and Link-Suite

New in 0.1.9. When VJ-Link starts, it plays the short animation every program of the Link-Suite shares: the programs fan out from the suite sign, the others return, and only VJ-Link flies onto its logo on the start screen. Then the start screen fades in. It takes at most 2.5 seconds.

CaseAnimation
First start of the programyes, once
New, open, language change, reloadno
After a crashno
“Reduce motion” on in the systemonly the logo fades in and out, about 1 s
Outputs (projector, LED wall, window output)never

Switch it under Settings → Interface → Start animation: Like the Link-Suite follows the setting of the launcher, Show and Don't show decide for VJ-Link alone.

  1. Logo: here the animation lands; VJ-Link becomes its logo with the name.
  2. Card “All programs in one place”: only when the launcher Link-Suite is not installed on this computer. It fades in after the animation.
  3. Get Link-Suite: opens the website of the Link-Suite in the browser. From now on this is the easiest way to install and update VJ-Link.
  4. Don't show again: the card stays away, also after a restart.

✎Note

VJ-Link only checks on this computer whether Link-Suite is installed. Nothing goes to the internet until you click Get Link-Suite. The card never appears in the demo project, while outputs are live or on an output.
