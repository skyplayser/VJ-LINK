Light desksZero 88 FLX

Zero 88 FLX, FLX S24/S48 and ZerOS.

ZerOS desks output Art-Net and sACN.

βBeta

Not yet tried with this desk. The steps follow the maker's manual; menu names can differ between software versions. Please tell us if it works: report a problem or on Discord.

Connection

On the desk

  1. Setup → Outputs, choose a universe.

  2. Enable Art-Net or sACN for it with the number VJ-Link listens to.

Patch

  1. Patch VJ-Link on the universe and start address you set in VJ-Link under Settings → DMX and network, as 91 channels: either as a fixture type built from the CSV channel list (Settings → DMX and network → Save channel list (CSV)) or as 91 single dimmers.

  2. Put the channels you need on faders or executors: master (1), scene (3), the color slots (9–28) and the layer opacities (29, 39, 49, 59) are a good start.

  3. Move a fader and watch CONNECT → Live values in VJ-Link: the bar of the channel moves, the DMX pill at the top turns green.
