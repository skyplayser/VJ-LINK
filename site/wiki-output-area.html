OutputsImage area, devices and profiles

LED controllers, projectors, profiles.

Every output has its own settings: a name, the image area in signal pixels, how the picture is fitted into it, and the device type with strobe and blinder. A typical case: an LED controller reports itself as a 1280 × 1024 monitor, but the LED wall only uses a small part of it. VJ-Link then draws the picture exactly into that part and leaves the rest black, while a projector next to it keeps showing the full picture.

The output rows

  1. Name of the output (here “LED wall”), below it the real screen and its resolution in pixels.
  2. Image area of this output, if it does not use the full screen.
  3. Device type: the projector gets no strobe and no blinder.
  4. Settings opens the dialog for this output.
  5. Open as output / Close. An open output also shows its frame rate and how long a frame takes.

Setting up an output

  1. Name, e.g. “LED wall left”. Empty: the name of the screen.
  2. Preview of the screen (black) with the image area (frame). Drag the area to move it; arrow keys move by 1 pixel, with ⇧ by 10.
  3. The corner changes the size; with ⌥ the arrow keys do the same.
  4. X, Y, width, height in signal pixels, counted from top left. Full area resets to the whole screen.
  5. Fit: Fit (black bars), Fill (cropped) or Stretch (distorted).
  6. Device: screen, projector or LED wall, with strobe and blinder on or off for this output.
  7. Show a frame on the output: a 1-pixel white edge exactly around the area, to find it on the wall. It ends when the dialog closes.
  8. More: show only a part of the picture, and a test pattern for this output alone.
  9. Done. Every change is live at once; Reset sets everything back.

✓Tip

The image area works with every arrangement: same picture, canvas and projection mapping. The picture of the output is finished first (canvas part, mapping, masks) and then placed into the area.

!Warning

Strobe and blinder off for a projector also means: strobe, strobe white, colour strobe and the blinder never reach this output, whatever the desk sends. Safe flashes still apply to all other outputs.

Output profiles

A profile remembers the arrangement, mapping, image areas, device types and names of all outputs, independent of the project. Save one per venue or setup, e.g. “Club A” and “Wedding”, and load it with any project.

  1. Choose a saved profile.
  2. Load it, or Delete it.
  3. Name for the current setup.
  4. Save: a profile with the same name is overwritten.

When loading, VJ-Link finds the screens again in this order:

  1. same screen ID and name,

  2. same name and resolution (e.g. after plugging into another port),

  3. same ID and resolution,

  4. same name, then same resolution.

A screen that cannot be found is named in a message (“missing: LED wall”); its settings are left out until you load the profile again with that screen connected.

Recipe: LED wall via an LED controller

  1. Connect the LED controller (sending card, video processor) to the computer like a monitor. In the controller software, note where the wall sits in its input: X, Y, width and height in pixels.

  2. OUTPUT: the controller appears as a screen, e.g. 1280 × 1024. Click Settings next to it.

  3. Name it “LED wall”, enter X, Y, width and height (e.g. 140, 56, 280, 112), device LED wall.

  4. Open as output, tick Show a frame on the output: the white edge must sit exactly on the outer pixels of the wall. Correct with the arrow keys, 1 pixel per press.

  5. Choose Fit: Fit keeps the aspect ratio (black bars), Stretch fills the wall exactly (distorted), Fill crops.

  6. Want the wall to show its own part instead of the full picture? Use Canvas or More → Show only part of the picture.

  7. Save everything as an output profile for this venue.

✓Tip

Even sharper: set Resolution → Pixels in VISUALS to the size of the area (e.g. 280 × 112). Then the picture is rendered in exactly that size and lands 1:1 on the wall pixels, which also saves graphics power.

Troubleshooting

ProblemSolution
The picture sits a few pixels off on the wallswitch on Show a frame on the output and move the area with the arrow keys until the edge sits on the outer LEDs
Windows shows 1279 or 1281 pixels instead of 1280VJ-Link reads the exact resolution from the monitor, also with display scaling (125 %, 150 %). If the controller reports a wrong size, set the resolution in the Windows display settings
The picture on the wall is blurryset the output resolution to the size of the area (VISUALS → Resolution → Pixels) and choose Stretch
No strobe on the projectorintended: projectors get no strobe or blinder by default. Tick Strobe in the settings of the output if the venue allows it
After loading a profile an output is missingconnect the screen and load the profile again; the message names the missing outputs
